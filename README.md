# Fasal-Netra
Agentic AI Crop-Loss Claim Assessment Platform

🌾 Overview

FasalNetra is an enterprise-grade, agentic AI platform designed to automate and streamline individual crop-loss claim assessments for agricultural insurance. Developed by TerraTrust Technologies, this system reduces claim settlement timelines from months to days, eliminates manual bottlenecks, and mitigates fraud while ensuring human oversight on critical decisions.

This repository houses the complete Software Development Life Cycle (SDLC), Agile DevOps, and Project Management Report, prepared as part of the Software Project Management coursework at IIM Bodh Gaya.

🚀 Key Features & Architecture

Multi-Agent Orchestration: Specialized agents handling intake (voice/WhatsApp), policy validation, satellite/weather evidence gathering (Sentinel-1/2 & IMD), damage estimation, fraud screening, and multilingual communication.

Hybrid Agile SDLC: Scrum-driven feature delivery combined with Kanban operational flow, robust CI/CD pipelines, and automated testing (TDD/BDD).

Scalable Cloud-Native HLD & LLD: Layered microservices architecture hosted on AWS (Mumbai region) utilizing PostgreSQL/PostGIS, object storage, and event-driven queues.

Strict Regulatory Compliance: Built-in adherence to India’s DPDP Act 2023, IRDAI guidelines, ISO/IEC 27001 security controls, and WCAG 2.2 AA accessibility standards.
